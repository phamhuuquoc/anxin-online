# 🙏 Xin Cơm Chú Ơi

> Website ăn xin online chuẩn nghèo khổ, đau đớn, không phải loại ăn xin kéo loa bật audio chay.

## ✨ Features

- **Font rách rưới** — UnifrakturMaguntia Gothic + Crimson Text italic, run rẩy bằng CSS animation
- **Bát nứt vỡ** — SVG tay vẽ chi tiết: vết nứt lớn, nứt nhỏ, mảnh vỡ trên vành, rêu mốc, vòng nước đọng
- **Nhân vật** — SVG người ngồi co ro: tóc thưa loà xoà, mắt trũng, má hóp, râu lưa thưa, chân cụt băng bó, nước mắt
- **Nền** — Màu đất bùn (`#2a1f0e`), vân giấy cardboard, SVG noise filter, scan-line overlay
- **Nam Mô A Di Đà Phật** — Marquee chạy vô hạn với pulse-glow vàng, có ☸️ và 🪔
- **Hiệu ứng**:
  - Toàn thân run rẩy (CSS shiver keyframe)
  - Nước mắt rơi từ đỉnh màn hình
  - Bát rung khi hover
  - Xu rơi vào bát khi donate
  - Alert đa dạng cảm ơn mỗi lần bỏ tiền
- **Tờ bìa carton** — clip-path răng cưa, texture chỉ ngang, cạnh rách
